# 인트로 연결형 운영체제 재설계

## 의도

Solvi를 단순한 유형 분석 화면이나 기능 모음이 아니라, 학생의 한 번의 채점 결과가 다음 학습과 학원 운영까지 이어지는 통합 시스템으로 보여 준다. 첫 화면에서 학습 흐름과 올인원 운영을 함께 이해할 수 있어야 한다.

## 목표

- 히어로의 분리된 S 심볼과 Solvi 워드마크를 하나의 시각적 기준선과 높이로 정렬한다.
- 기존 소개 문장 `Solvi(솔비)는 … 통합 플랫폼이에요.`를 삭제한다.
- 메인 앱의 취약 유형 지도와 겹치는 히어로 표현을 연결형 운영체제 장면으로 바꾼다.
- QR 채점 결과가 취약 개념, 다음 학습지, 수업 배정, 상담 기록, 학부모 알림으로 이어지는 실제 제품 흐름을 보여 준다.
- 상단 목차와 학원의 하루 단계가 해당 위치로 정확히 이동하고 현재 위치를 알려 주게 한다.
- 기능 전체를 반복 카드 격자 대신 빠르게 훑을 수 있는 비대칭 분야별 디렉터리로 재배치한다.
- 현재 지원 4과목과 앱에 `준비 중`으로 등록된 과목을 모두 지원 과목 영역에 반영한다.
- 기존 기본 스크롤을 유지하면서 토스·Apple식 진행감, 깊이, 연결감을 보강한다.

## 하지 않을 것

- 실제로 제공하지 않는 자동화, AI 기능, 성과 수치, 고객 수를 만들지 않는다.
- 기존 QR 채점, 학원의 하루, 요금제, 개발자 설정 연동을 제거하거나 다시 작성하지 않는다.
- 스크롤을 가로채거나 관성 스크롤 라이브러리를 추가하지 않는다.
- 무거운 blur, backdrop-filter, 큰 그림자, 동영상, 새 외부 라이브러리를 사용하지 않는다.
- 메인 앱 기능이나 데이터 구조는 바꾸지 않는다.

## 선택한 접근

### 1. 연결형 운영체제 — 선택

중앙의 학생 기록을 기준으로 `QR 채점 → 취약 개념 → 다음 학습지 → 수업 배정 → 상담 기록 → 학부모 알림`이 차례로 연결된다. 학습과 운영을 별도 제품처럼 나누지 않고 한 학생의 기록에서 움직이는 하나의 시스템으로 표현한다. 데스크톱에서는 연결 구조를 넓게, 휴대폰에서는 세로 타임라인으로 재배치한다.

### 2. 이중 트랙 — 제외

학습과 운영을 좌우에서 동시에 진행하면 비교는 빠르지만 작은 화면에서 복잡하고, 둘이 하나의 기록으로 이어진다는 메시지가 약해진다.

### 3. 하루 전체 시네마틱 — 제외

시간순 이야기는 이해하기 쉽지만 기존 `학원의 하루` 9장면과 중복된다. 새 히어로는 하루가 아니라 시스템의 연결 원리를 맡는다.

## 화면 설계

### 히어로

- 두 SVG를 나란히 놓는 현재 구조를 정리해 심볼과 워드마크가 같은 높이·기준선에서 하나의 로고처럼 보이게 한다.
- 삭제되는 소개 문장 자리에는 일반 설명문을 넣지 않는다.
- 제목은 현재 제품의 핵심인 `채점이 끝나면, 다음 수업이 시작됩니다.` 계열의 직접적인 문구로 다듬는다.
- 오른쪽 시각물은 취약 유형 지도 대신 연결형 운영체제 미리보기로 바꾼다. 학생 기록을 중심으로 학습과 운영의 다음 행동이 연결되어 있음을 첫 화면에서 보여 준다.
- 실제 제공 기능만 사용하고 학생 이름·성적은 예시임을 표시한다.

### 연결형 스크롤 장면

- 기존 한 바퀴와 연결 그래프의 역할이 겹치지 않도록, 히어로 미리보기는 요약하고 기존 연결 구간은 전체 흐름을 설명하는 본 장면으로 강화한다.
- 스크롤 진행에 맞춰 노드와 연결선이 순서대로 활성화된다.
- 큰 이동은 현재 위치에서 이어지는 transform/opacity만 사용하며 최대 300ms의 직접 조작 피드백을 지킨다.
- 되감아 스크롤하면 같은 순서로 자연스럽게 되돌아간다.
- `prefers-reduced-motion`에서는 완성된 연결 구조와 짧은 투명도 전환만 보여 준다.

### 내비게이션과 구간 이동

- 상단 목차의 모든 항목을 실제 섹션 ID와 일치시킨다.
- 고정 헤더 높이를 고려한 `scroll-margin-top`으로 제목이 가려지지 않게 한다.
- 현재 구간은 `aria-current`와 짧은 진행선으로 표시한다.
- `학원의 하루`의 9개 시간 항목은 버튼처럼 누르면 같은 sticky 무대 안의 해당 진행 위치로 이동한다.
- 키보드와 동작 줄이기 환경에서도 즉시 이동할 수 있어야 한다.

### 기능 전체

- 동일한 흰 카드 33개를 한 화면에 반복하지 않는다.
- 왼쪽에는 분야 목록과 기능 개수, 오른쪽에는 선택 분야의 핵심 기능을 제목·짧은 설명·세부 항목의 세 단계 위계로 보여 준다.
- 데스크톱은 비대칭 4:8 구조, 태블릿과 휴대폰은 분야 탭 아래 단일 열로 바꾼다.
- 분야를 바꿀 때 위치 이동 애니메이션은 넣지 않고 내용은 즉시 바뀐다. 선택 상태만 색과 짧은 opacity 전환으로 알린다.

### 지원 과목

- 현재 지원: 물질과 에너지, 세포와 물질대사, 역학과 에너지, 화법과 언어.
- 준비 중: 앱의 `SUBJECTS` 상수에 정의된 과목을 단일 출처로 맞춰 모두 노출한다.
- 과학·사회·수능 맞춤형으로 묶고, 학년과 `지원 중`/`준비 중` 상태를 명확히 구분한다.
- 현재 지원 4과목의 교재 표지는 대표 시각물로 유지하되, 제목과 설명은 `네 과목`처럼 고정된 숫자를 쓰지 않는다.

## 모션 원칙

- 브라우저 기본 스크롤과 1:1로 연결하며 스크롤을 가로채지 않는다.
- 스크롤 진행 표시, 연결선 그리기, 레이어 깊이, 장면 간 겹침을 추가하되 transform과 opacity만 갱신한다.
- 탭 선택, 기능 분야 변경, 키보드 조작에는 이동 애니메이션을 넣지 않는다.
- hover는 fine pointer 조건 안에서만 제공하고 눌림 피드백은 즉시 준다.
- 휴대폰에서 가로 방향으로 화면 밖에서 요소를 들여오지 않는다.

## 구현 제약

- 기존 정적 HTML/CSS/JavaScript 구조를 유지한다.
- 주요 수정 파일은 `intro.html`, `intro.css`, `intro.js`, 관련 인트로 테스트, `AGENTS.md`, `WORKLOG.md`, `sw.js`다.
- `intro.css`와 `intro.js` 버전, `sw.js`의 `VER`을 함께 올린다.
- 과목 목록은 앱과 소개 페이지가 어긋나지 않도록 테스트로 고정한다.

## 검증 기준

- 정적 파싱과 인트로 회귀·스크롤 테스트가 통과한다.
- 1440px, 820px, 390px에서 직접 캡처해 로고 기준선, 가로 넘침, 텍스트 가독성, sticky 장면 위치를 확인한다.
- 상단 목차와 학원의 하루 9단계를 눌렀을 때 목표가 헤더 아래에 정확히 보인다.
- 동작 줄이기와 JavaScript 비활성 상태에서도 핵심 설명과 모든 과목이 보인다.
- 실제 기기에서 확인하지 못한 항목은 완료 보고에 명시한다.
