# 개념 정리 바깥쪽 필기 여백

## 의도

교재의 개념 정리 쪽을 일반 문제집처럼 펼쳤을 때 바깥쪽에 바로 필기할 수 있게 한다. 홀수 쪽은 오른쪽, 짝수 쪽은 왼쪽에 32mm 필기 공간을 둔다.

## 범위

- `p.k === 'cn' && p.kind === 'c'`인 개념 정리 쪽에만 적용한다.
- 문제, 지문, 정답·해설, 표지, 차례, 별도 노트 쪽은 현재 레이아웃을 유지한다.
- 화면 미리보기, eBook, 인쇄, PDF가 모두 같은 쪽 HTML을 사용하므로 동일하게 반영한다.

## 레이아웃

- A4의 기존 좌우 12mm 안전 여백은 유지한다.
- 개념 본문 폭은 186mm에서 148mm로 줄여 다시 조판한다.
- 바깥쪽 필기 면은 32mm, 본문과 필기 면 사이는 6mm로 둔다.
- 홀수 쪽: 안쪽(왼쪽) 본문 148mm → 6mm 간격 → 오른쪽 필기 면 32mm.
- 짝수 쪽: 왼쪽 필기 면 32mm → 6mm 간격 → 안쪽(오른쪽) 본문 148mm.
- 필기 면에는 선, 점, 라벨, 테두리를 넣지 않는다. 기존 교재의 아주 옅은 과목색(`--pl`)으로 면만 채운다.
- 머리글과 바닥글은 기존 전체 폭을 유지한다.

## 조판

- 개념 단위의 측정 폭도 148mm로 바꿔 표·그림·문장이 실제 본문 폭에서 줄바꿈되도록 한다.
- 줄바꿈 증가로 개념 쪽 수가 늘어나는 것은 허용한다.
- 페이지 높이 측정과 넘침 검사를 다시 실행한다.

## 검증

- 홀수 개념 쪽의 오른쪽, 짝수 개념 쪽의 왼쪽에만 32mm 필기 면이 있는지 실제 교재로 확인한다.
- 문제·지문·해설 쪽에는 필기 면이 생기지 않는지 확인한다.
- `node tools/measure_books.js`로 교재 높이를 재측정한다.
- 인쇄/PDF 회귀 및 전체 `npm test`를 실행한다.

## 고려한 방식

- **32mm 과목색 면 + 148mm 재조판 — 선택:** 필기 공간과 본문 가독성의 균형이 가장 좋고, 사용자가 고른 방식이다.
- 32mm 줄 노트: 필기 안내는 명확하지만 사용자가 원하지 않아 제외한다.
- 기존 186mm 본문을 옆으로 이동: 내용이 잘리고 실제 필기 폭이 생기지 않아 제외한다.
