# 로그인·로딩·인트로 정제 디자인

## 의도

로그인 시작 화면은 한 가지 행동(계정 로그인)에 집중시키고, 처리 중 화면은 진행률과 남은 예상 시간을 보여 불확실성을 줄인다. 소개 페이지는 기존의 실제 서비스 화면·스크롤 이야기 구조를 보존하면서, 전달받은 Apple 레퍼런스의 밝은 전시형 캔버스와 차분한 네이비 대비를 적용한다.

## 목표

- 전역 로딩 상태에 정수 진행률과 `약 N초 남음` 추정치를 함께 표시한다.
- 로그인 카드에서 `번호로 바로 채점` 보조 행동을 없애고, 간격을 일관된 8px 단위 리듬으로 조정한다.
- Pretendard를 유지한다. 새 라이브러리·웹폰트·글래스 효과는 추가하지 않는다.
- 인트로는 한 가지 파란 행동색과 밝은 회색/화이트 표면, 네이비 대비 섹션, 절제된 테두리·그림자로 고급스럽고 활동적인 인상을 만든다.

## 비목표

- 기존 실제 캡처, 기능 문구, 스크롤 상호작용, 접근 경로를 재구성하거나 새 제품 약속을 만들지 않는다.
- 로딩 시간의 정확한 보장은 하지 않는다. 문구는 현재 진행률로 계산한 예상치다.

## 선택한 접근

1. 전체 인트로 구조를 새로 만들기: 시각 변화는 크지만 검증된 스크롤 무대·모바일 배치 위험이 크다.
2. 기존 구조의 표면과 계층을 재구성하기: 기존 기능을 보존하면서 레퍼런스의 분위기를 일관되게 반영한다. **선택.**
3. 색상만 교체하기: 위험은 작지만 사용자가 요청한 고급스러운 변화에는 부족하다.

## 제약

- UI 문구는 한국어, 글꼴은 Pretendard.
- 모션은 300ms 이하이며 transform/opacity만 사용하고, `transition: all`은 쓰지 않는다.
- 모든 hover는 정밀 포인터 미디어 쿼리 안에 둔다.
- 배포 자산 변경 시 HTML의 자산 쿼리 버전과 `sw.js` `VER`을 갱신한다.
