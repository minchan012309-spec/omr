# 개념 교재 단원명과 필기 공간 재조판

## 의도

개념이 잘리지 않고 읽히면서도 일반 문제집처럼 바깥쪽에 충분한 필기 공간을 둔다. 단원명 카드는 필기 공간에 눌리지 않게 페이지 전체 본문 폭을 사용한다.

## 확정 레이아웃

- 적용 대상은 `p.k === 'cn' && p.kind === 'c'`인 개념 정리 쪽뿐이다.
- 단원명 카드(`.sbn`)는 좌우 12mm 안전 여백 안의 186mm 전체 폭을 사용한다.
- 단원명 카드가 있는 쪽은 필기 공간과 개념 본문이 카드 아래에서 시작한다.
- 홀수 쪽은 오른쪽, 짝수 쪽은 왼쪽에 40mm 필기 공간을 둔다.
- 본문과 필기 공간 사이는 6mm, 개념 본문 폭은 140mm다.
- 필기 공간은 `var(--pl)` 단색의 각진 직사각형이다. 선·점·라벨·테두리·라운딩을 넣지 않는다.
- 개념 본문 기본 글자 크기는 11px로 줄이고, 높이 측정도 같은 크기와 140mm 폭으로 다시 수행한다.
- 머리글·바닥글과 문제·지문·해설·표지·차례·별도 노트는 기존 배치를 유지한다.

## 접근 방식

- **쪽 계획의 전체 폭 상단 영역 사용 — 선택:** 기존 `bkPack`의 `top/topH`를 사용해 단원명 카드를 실제 조판 단계에서 분리한다. 높이 계산과 화면 출력이 일치한다.
- 렌더링 때 문자열로 단원명만 추출: 구현은 짧지만 쪽 계획의 높이와 실제 위치가 어긋나 잘림이 재발할 수 있어 제외한다.

## 검증

- 실제 화법과 언어 개념서에서 단원명 카드 186mm, 본문 140mm, 필기 공간 40mm, 간격 6mm, 글자 11px를 브라우저 위치로 검사한다.
- 단원명 카드 아래에서 필기 공간이 시작하고 개념 내용이 실제로 보이는지 검사한다.
- 국어 지문 쪽에는 이 레이아웃이 적용되지 않는지 검사한다.
- 전 과목 높이 재측정, 인쇄/PDF 회귀, 전체 테스트를 실행한다.
