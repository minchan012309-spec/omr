## 발표 자료 쓰는 법
- `solvi-presentation.html`을 Chrome으로 연다(`fonts` · `img` · `lib` 폴더가 옆에 있어야 함). 인터넷 없이 동작.
- **슬라이드쇼**: `▶ 슬라이드쇼` 또는 `F5`. 마우스 없이 리모컨으로 진행.
  - 다음 = → · ↓ · PageDown · Space · Enter / 이전 = ← · ↑ · PageUp · Backspace
  - 슬라이드마다 전환 효과(줄무늬 · 문 · 확대 · 원형 · 밀기 · 뒤집기)만 있고, 눌러서 하나씩 나오는 단계는 없다.
  - `B`/`.` 검은 화면, `S` 발표자 메모
- **7번 라이브 시연**: 다음을 누를 때마다 한 단계씩(9단계) — 유형 선택 → 학습지 생성 → QR 인식 → 답 입력 → 채점 → 해설 → 오답 학습지 → 2회차 채점 → 회차 비교.
- 14번 「실제 화면 훑기」, 18번 「카드뉴스 홍보」, 19번 「찾은 문제 · 수정」.
- **편집 모드(기본 화면)**: 왼쪽 목록에서 슬라이드 선택, 글자를 눌러 바로 수정(자동 저장). `HTML로 저장`으로 고친 파일을 내려받아 이 폴더에 덮어쓴다. 편집 모드에서는 모든 단계가 다 보인 상태로 표시된다.

## 데이터 주의
- 7 · 9번 슬라이드와 보고서 3.3 · 3.4절의 풀이 기록은 **시뮬레이션 데이터**(고정 시드)이며 그렇게 표시되어 있다.
- 19번 슬라이드와 보고서 3.6.3절의 문제 · 수정 목록은 테스트 기간의 저장소 커밋 기록에서 가져왔다. 학교별 인원 · 만족도 설문은 집계하지 않아 넣지 않았다.
- 라즈베리파이 응답 시간 · SD/SSD 속도는 측정하지 않았다(보고서 4.2절 제언).
