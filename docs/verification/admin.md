# 행정 기능 검증 · 2026-10-29

## 구현

기존 학원 운영의 원생 목록에서 통합 상세를 연다. 반·보호자 연락처, 최근 출결 최대 365건, 상담, 수납 및 학습 최대 200회를 표시하며 학부모용 학습 보고서를 인쇄할 수 있다. 학습은 실제 attempts.items의 c/r 결과를 합산한다. 유형 정보가 없으면 유형 미분류로 표시한다.

기존 학원 운영 안의 운영 업무 탭에서 마감일·담당자·연결 학생·반복 주기를 저장한다. 반복 완료는 ops_complete_task RPC로 처리한다. 상담 예약은 한국 시각으로 저장하며 종료 역전과 담당자 예약 중복을 막는다. 휴강·대체수업을 저장하고 학생·학부모 시간표 및 오늘 수업에서 원래 수업을 제외하고 변경 내용을 표시한다. 원장은 직원 역할을 바꿀 수 있다.

ops_access가 있으면 학습·수납·직원 관리 권한을 적용한다. 강사에게 fees를 요청하지 않고 행정 직원에게 attempts를 요청하지 않는다. 권한 확인의 연결 오류는 접근을 차단한다. 구 DB에서 RPC가 없으면 기존 기능을 유지하며 새 운영 기능의 마이그레이션 요구를 표시한다. 월 일괄 청구는 ops_monthly_bill만 호출하며 구 DB의 개별 INSERT로 대체하지 않는다.

월말 조회는 AcademyCore.monthRange를 사용한다. 반 편집은 종료 역전·동일 반 시간 중복·강사/강의실 충돌과 잘못된 금액을 차단한다. CSV는 화면의 검색·상태·반 필터와 정렬을 적용하고 수식 입력을 무력화한다. 조퇴 상태를 출결 버튼과 월간 요약에 추가했다. 모바일 표는 수평 스크롤, 폼은 테마 surface/text 토큰을 사용한다.

## 실행 검증

- `node --check lazy/admin.js`, `node --check lazy/acad.js`: 통과.
- `node tests/admin-regression.cjs`: 로컬 Chrome + Playwright의 격리 API fixture 브라우저 검증 통과. 모든 네트워크 요청을 차단하고 테스트 전용 DOM에 실제 세 스크립트를 로드한다.
- 실제 클릭·입력·핸들러를 통해 통합 상세의 보호자/조퇴/정답률, 반복 업무 저장 및 완료 RPC, 한국 시각 상담 저장과 역전 거부, 휴강/대체 저장, 월 청구 RPC와 fees INSERT 부재, 2월 28일 조회, 역할별 불필요 API 요청 부재, 반 시간 역전/겹침 거부, 직원 역할 RPC, 학부모 시간표 취소 반영, 생성된 학습 인쇄 HTML 내용을 확인했다.
- CSV 수식 인코딩과 활성 필터도 확인했다.

## 검증 한계

실제 Supabase 또는 운영 개인정보에 연결하지 않았다. 본 검증은 UI/API 계약 테스트이며 DB의 RLS·테넌트 분리·동시성·월 청구 멱등성 보장은 별도 SQL 검증이 필요하다. 실물 인쇄, 실제 프린터, 알림 발송, 실제 결제는 실행하지 않았다. 보고서 HTML 내용은 검증했으며 물리적 인쇄 결과는 검증하지 않았다. 직원 역할 변경 후 이미 열린 다른 클라이언트의 화면은 다음 로드에 갱신되며 최종 접근 차단은 DB 정책이 담당한다.

## 권한 통합 후 추가 검증

학생 생성·수정의 representation 응답은 `select=id,name,grade,memo`를 명시한다. 비밀번호 해시 SELECT 권한을 제거한 스키마에서도 비밀번호 열을 요청하지 않는다. 브라우저 fixture에서 두 변경 요청의 명시 열 선택을 검증했다. 학부모 계정 발급·폐기는 원장(manage)이 담당하고 학생 로그인 발급·폐기는 학습 권한이 필요하도록 별도 SQL과 공통 UI에서 제한한다.

월 청구 미리보기는 `billing_key = 월:반ID:학생ID`로 중복을 판정한다. 키 없는 기존 청구에만 제목 비교를 적용한다. 동명 반 두 개 중 한 반만 청구된 경우 다른 반이 예정에 남고, 키 있는 반의 이름을 바꿔도 이미 청구로 유지되는 fixture를 검증했다.

권한 캐시는 계정 ID와 연결하고 계정이 바뀌면 재조회 전 사용을 거부한다. 권한 RPC가 이전 계정에서 늦게 도착한 경우도 새 계정에 적용하지 않는다. 강사·직원 분리 외에 계정 전환 시 이전 billing 허용 캐시가 재사용되지 않는 검증을 추가했다.

대체수업 저장은 `AcademyCore.datedConflicts`로 실제 날짜의 정규수업·휴강·대체수업을 합쳐 충돌을 검사한다. 반의 기본 강의실·강사를 상속하며 다른 대체수업과의 충돌 거부, 같은 날짜에 휴강된 정규수업과의 거짓 충돌 해소를 실제 저장 핸들러 fixture로 검증했다.
