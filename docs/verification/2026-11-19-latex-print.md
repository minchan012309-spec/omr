# 신규 자료 브라우저 LaTeX 출력 검증

## 구조

- 기존 출력 버전 없는 자료는 HTML. 신규 학습지/복제/교재/모의고사만 `xelatex-v1`.
- 브라우저 XeTeX·xdvipdfmx Worker에서 조판. 별도 조판 서버·유료 API 없음.
- 지정 네 폰트는 브라우저에만 등록. 원본 파일 해시 확인. Supabase에는 쪽별 코드·번호·자료 식별자만 저장.
- `books.js?v=87`, 서비스 워커 `solvi-v215`. 기존 HTML 높이표와 과목 데이터는 변경하지 않음.

## 확인한 항목

- 제공 ZIP의 실제 원본 PDF 첫 7쪽과 같은 TeX를 지정 폰트로 Chrome 안에서 조판. 7쪽 생성, 첫 쪽 텍스트 동일, 원본과 첫 쪽 육안 대조 및 7쪽 래스터 대조.
- HWP 5.x 내부 미리보기·DocInfo 글자 모양·Section0 용지 확인. 용지 771.02×1116pt. 제목 Bold 25pt/장평85%, 과목명 Bold46pt, 본문 Medium17pt를 A4 비율로 변환. 긴 원본 제목을 넣은 표지를 네이티브 XeLaTeX로 두 번 조판해 육안 확인.
- 물질과 에너지·세포와 물질대사·역학과 에너지·화법과 언어·인공지능 수학 각 실제 4문항의 표지·문제·정답/해설 PDF 생성.
- 실제 교재 만들기 함수로 신규 교재 생성, 개념·문제·해설 PDF, 출력 명세 저장과 채점 쪽수 비교.
- 실제 `G-cm33-0002`의 CSS 분수 구조를 분자/분모 LaTeX로 보존해 PDF 생성.
- 5지선다 원본 매크로와 다른 개수 선지, 표 제목 분리, 병합 표, MathML 첨자·분수, SVG 2배 해상도와 전체 그림 범위 확인.
- 원본 폰트 최초 등록, 수정 가능한 제목·과목명·기관명·필적확인·유의사항·표지, 1440/820/390px 출력 설정 확인. Chrome 내장 PDF 프레임의 자동 폰트 대기 때문에 화면 캡처는 UI 폰트 로드를 확인한 뒤 CDP 캡처 사용.
- 버전 없는 자료와 신규 자료 구분, 교재 회차, 인쇄 번호로 문항 선택, 여러 쪽 연속 채점, 로그인 복귀, PDF 재출력 후 같은 문항 묶음의 제출 잠금 키 유지.
- 최종 6개 PDF에서 표지를 제외한 QR 35개를 해독해 명세 ID와 실제 물리 쪽 번호 일치 확인.
- 엔진 래퍼의 전역 `exports` 격리 후 기존 `jsQR` 로드 확인.
- SQL은 PGlite에서 명세 불변성, 버전 검증, 개인 정보 제거, 전체 목록 조회 차단을 검증. 운영 DB로 요청하지 않도록 브라우저 테스트의 Supabase 요청은 격리.

## 실행

```sh
node --test tests/print-engine.test.cjs tests/latex-document.test.cjs
node tests/latex-manifests.cjs
npm test
# 원본 폰트가 있는 로컬 전용 검증 (정적 검증 서버 BASE 필요)
SOLVI_LATEX_FONTS=/path/to/private-fonts BASE=http://localhost:8765 node tests/latex-browser.cjs
```

원본 폰트는 공개하지 않으므로 일반 CI의 실제 폰트 조판은 건너뛰며, 메타데이터·레거시·DOM·SQL 검사는 실행한다. 로컬에서는 원본 네 폰트를 등록해 위 실제 PDF 검사를 수행했다. 전체 회귀 도중 기존 인쇄 검사에서 페이지 로딩 시간 초과가 한 차례 발생했고 단독 재실행과 최종 전체 `npm test`는 모두 종료 코드 0으로 통과했다. 최종 원본 폰트 검증은 인공지능 수학·세포와 물질대사, 신규 교재, CSS 분수, 세 화면 너비를 다시 확인해 종료 코드 0으로 통과했다.

## 운영 반영 전

`supabase/sql_27_latex_manifests.sql`을 기존 프로젝트에 한 번 적용해야 신규 QR 명세를 저장할 수 있다. 폰트는 각 생성자 브라우저에 최초 한 번 등록한다. 운영 DB 적용·사이트 배포·PR 병합, 실제 Safari/Windows/휴대폰 기기·카메라·종이 인쇄는 이번 로컬 검증에 포함하지 않는다. Chrome에서 화면 너비를 바꾼 결과를 실제 기기 검증으로 간주하지 않는다.
