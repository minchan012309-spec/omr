# LaTeX 양식·실시간 편집·기존 교재 디자인 교정

## 변경 범위

- 이미 만들어진 자료의 HTML 출력 경로는 유지한다.
- 신규 학습지·모의고사는 첨부 시험지 본문과 HWP 표지로 조판한다. 교재는 기존 디자인을 보존한 별도 LaTeX 경로다.
- 원본 폰트 4개는 사용자의 후속 지시에 따라 정적 사이트에 탑재한다. 업로드 UI·최초 등록을 없앤다. 기존 교재 글꼴 14개도 원본 WOFF2의 문자표·폭·윤곽과 일치하는 SFNT로 변환하고 필요할 때만 불러온다.
- 원문의 세로 선지, 지문 박스, 공통 지문 제목, 밑줄을 보존한다. 조합형은 실제 너비로 ①②③ / ④⑤를 선택하고 같은 열에서 시작한다. 해설은 2단. 첫 두 줄만 단 끝에 남지 않도록 나눔을 제한한다.
- 짧은 12문항을 실제 높이로 측정해 4문항씩 3쪽으로 배치했다. 원본과 대조한 첫 쪽 문항 시작은 약 77.1/174.7mm, 후속 쪽은 약 24.9/142.5mm이며 97.5/117.5mm 칸 간격을 유지한다. 긴 문항은 나누지 않고 들어갈 다음 단으로 이동하거나, 한 단을 넘는 지문은 이어지는 박스로 처리한다.
- HWP 표지는 안내문을 항목 목록으로 조판해 줄 간격·들여쓰기를 일정하게 하고, 답안지와 하위 정답/해설 목록을 구분한다.
- 생성 전 디자인 화면 및 출력 창에서 실제 PDF가 자동 갱신된다. 유형명·문항코드·디자인·글꼴·크기를 수정한다. 창별 취소와 최신 결과만 적용하는 대기열을 사용한다.
- 미리보기는 서버에 쓰지 않는다. 저장·인쇄할 때만 QR 명세와 출력 기록을 저장한다. 다른 출력창의 교재 회차/변경을 병합해 보존한다.

## 실제 출력 확인

- `N-002`, `N-003`, `N-005` 원문으로 박스 밖 공통 제목, 중복 지문 제거, 3+2·세로 선지, 밑줄, 2단 해설을 확인했다.
- 신명조 기본 PDF와 Pretendard 11.5pt·테두리형 PDF, 생성 전 KoPubWorld 11pt·간결형 자동 갱신을 실제 조판했다.
- 정적 파일만 제공한 환경의 국어 4쪽 샘플: 최초 약 2.0~2.5초, 재조판 약 1.7~1.8초. 특정 기기의 측정값이며 모든 교재의 속도를 보장하지 않는다.
- 기존 교재 표지·문제 쪽의 HTML과 native XeTeX PDF를 비교했다. 글꼴·페이지 위치를 보존하고 본문은 선택 가능한 텍스트다. 장식·그림·일부 수식은 원래 렌더링을 배경 자산으로 보존한다. 원본과 작은 화면 픽셀 차이는 남으며 모든 출력이 픽셀 단위로 완전히 동일하다고 주장하지 않는다.
- 압축 전 21,259,871바이트 2쪽 샘플이 89,791바이트로 감소했다. 서로 다른 QR 영역을 제외한 전 픽셀이 동일하고 본문 텍스트도 유지됨을 확인했다. 엔진이 넘기던 `compress=false`를 고정 호출의 해당 인수만 켰다. 재현 스크립트는 WASM SHA-256이 다르면 중단한다.
- 최종 5과목 PDF와 신규 교재 PDF의 QR 26개를 직접 해독해 각각 실제 물리 쪽 번호가 맞는지 확인했다. 신규 개념·문제·해설 교재 11쪽은 약 405KB로 생성되었고 저장된 채점 명세의 쪽 수와 일치했다.
- 기존 교재 생성기의 7개 표지·색상·글꼴·로고·실시간 미리보기, eBook 경로를 복구했다. 이미 만들어진 HTML 교재는 변경하지 않는다.

## 자동 검사

`npm test`는 단위·SQL·기존 앱 회귀와 함께 `latex-live.cjs`, `latex-fidelity.cjs`, `latex-creator.cjs`, `latex-book-layout.cjs`를 실행한다. 기존 확장 과목 검사는 `SOLVI_LATEX_SUBJECTS`/`SOLVI_LATEX_FONTS`로 추가 실행했다. 실제 PDF 검사는 이제 사이트 폰트를 자동으로 불러오므로 사용자 폰트 등록이 필요 없다.

확인한 브라우저 화면 폭: 1440 / 820 / 390px. 실제 Safari/Windows/휴대폰 기기, 카메라 및 종이 인쇄는 확인하지 않았다. 운영 DB SQL 적용·배포·병합도 수행하지 않았다. 기존 Supabase SQL27은 여전히 신규 QR 최종 저장 전에 필요하다.
