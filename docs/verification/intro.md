# Solvi 인트로 검증 — 2026-10-30 (시네마틱 스크롤 재제작)

## 구현

- `intro.html`, `intro.css`, `intro.js` + `lib/gsap/`(GSAP 3.12.5 · ScrollTrigger, 저장소에 동봉)로 빌드 없는 정적 배포 유지.
- 고정(pin)된 필름 하나와 스크럽 타임라인 하나가 10개 장면을 잇는다: Pro Display XDR 첫 화면 → 디스플레이 속 대시보드 → 문제은행 → 교재 넘김 → 태블릿 · 노트북 → OMR 채점 → 오답 분석 → 학원 운영 → 전체 기기 → 밝은 CTA. 스크롤을 올리면 그대로 되감긴다. 스냅 · 스크롤 가로채기 없음.
- 기기(Pro Display XDR · MacBook · iPad · iPhone)는 실제 비율로 만든 CSS 3D 모형이고, 화면 속은 실제 앱 캡처다. 책장은 12개(모바일 6개) 띠로 나눠 종이가 휘며 넘어간다.
- 모바일(860px 이하)은 같은 필름을 기기 크기 · 배치만 바꿔 가볍게 재생한다. reduced motion · 저사양(코어 2개 이하 · 메모리 2GB 이하 · 데이터 절약) · no-JS는 같은 장면을 정적으로 보여 준다.
- 로그인 목적지(`index.html?app=1#login`, `#student`, `?app=1`)와 `omr_app` localStorage 규약, 요금제 조회(`site_config` pricing)와 실패 시 기본 카드 유지.
- 바닥글의 이용약관 · 개인정보처리방침은 `policy.html`(초안, 법률 검토 필요).
