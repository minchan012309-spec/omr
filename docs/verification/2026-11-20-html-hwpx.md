# HTML 출력 복원 · 평가원 · 편집 가능한 HWPX

- 최신 지시로 LaTeX 생성 경로를 폐기하고 기존 HTML 미리보기·인쇄·PDF 저장을 복구했다. 신규 기록도 HTML이며 과거 인쇄 QR의 읽기 호환만 유지한다. 서비스워커/출력 경로는 조판 엔진을 불러오지 않는다.
- 기존14개 디자인에 평가원을 추가했다. 신명조 본문·KoPubWorld 돋움 머리말/표지, 성명·수험번호·필적 확인·유의사항·쪽 범위를 포함한다.
- 학습지 출력창과 교재 읽기·eBook·인쇄창에서 HWPX를 다운로드한다. 본문·제목 글꼴을 선택하고 제공 원본 글꼴도 받을 수 있다.
- 본문·표·상자와 수식은 native 한컴 개체, 그래프·그림은 PNG다. MathML·CSS 분수·명시 수식·지수/아래첨자·명확한 본문 산술식을 한컴 수식으로 변환한다. 글꼴은 참조하며 내장하지 않는다. 편집 문서 재흐름과 장식 CSS 차이로 정밀 위치는 HTML과 다를 수 있다.
- 모든 교재의 좌/우22mm 필기 여백을 독립 선택하며 국어의 개념 필기 공간·노트를 켜고 끈다. 실제 너비로 재배치하고 큰 문항은 넓은 본문으로 옮긴다. QR에는 레이아웃 설정이 남는다.

## 최소 확인

사용자 크레딧 절약 요청으로 전체 반복 검사·추가 검토는 생략했다.

- 정적 스크립트17개 파싱과 HTML 기본 계약3개 통과.
- 실제 평가원 표지·글꼴과 학습지/교재 HWPX 다운로드 버튼으로 파일 생성·선택 글꼴·native 수식/본문 확인. 최종 확인 파일: `/tmp/solvi-evaluation-editable.hwpx`, `/tmp/solvi-book-editable.hwpx`.
- HWPX ZIP/XML·표·그림·글꼴·수식, 문제은행 MathML 태그, 지수의 밑 보존, 본문 산술식/날짜/문항코드 구분 집중 검사 통과.
- 실제 한컴 한글에서 초기 샘플 `/tmp/solvi-editable.hwpx`를 오류 없이 열었다. 본문을 수정/취소하고 분수를 더블클릭해 수식 편집기·`{1} over {x ^{2}}`·HancomEQN을 확인했다. 사용자 원본은 수정하지 않았다.
- 여백 구현 때5과목·국어 전체 유형서의 너비/넘침과1440/820/390px 옵션을 확인했다. 국어 높이4814개 측정 후 기본 높이의 소폭 변동은 출판된 쪽수 보존을 위해 반영하지 않았다.

병합·운영 배포, 최종 모든 자료의 한컴 인쇄·실물 인쇄, 실제 Safari/Windows/휴대폰 검사는 수행하지 않았다.
