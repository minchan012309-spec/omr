# 교재 탐색·채점 및 컬러 인쇄 시안

## 사용자 요구
- 학습지·교재 인쇄 디자인을 전면 교체할 후보를 많이 제시한다. 기본형부터 시험지까지 모두 컬러로 만든다.
- 선택·승인된 인쇄 시안만 제품에 반영한다. 현재 단계에서는 기존 인쇄 디자인을 교체하지 않는다.
- 교재 탭은 배포받은 교재를 목록으로 찾고 대단원 → 중단원 → 소단원 순으로 이동한다.
- 채점할 범위를 쉽게 고르고, 처리 중 로딩을 보여 주며 중복 클릭이 여러 채점 화면을 만들지 않게 한다.

## 구현된 탐색·채점
- 기존 저장·배포·삭제 권한과 교재 계획을 재사용한다. 표지 카드를 이름·배포 정보·동작이 있는 목록으로 교체한다.
- 실제 `plan.pages[].sub`로 대단원과 중단원을 묶고, 개념 절 제목을 본문에서 찾아 세부 목차로 연결한다. 개념 절 정보가 없는 구성은 실제 구성별 첫 쪽을 보여 준다. 단원 정보를 임의로 만들어 넣지 않는다.
- 전체 회차형 교재는 기존 회차 선택을 유지한다. 본문은 기존 eBook을 재사용하므로 필기·쪽 번호·QR·채점 기록 규칙을 유지한다.
- 범위 선택은 교재 → 단원·구성 → 쪽 버튼 순서다. 선택 쪽·문항 수를 확인한 뒤 채점한다. 여러 쪽을 합치는 새 채점 기록 형식은 만들지 않았다.
- 공유 단일 실행 잠금과 즉시 로딩 표시를 적용한다. 처리 전에 브라우저가 표시를 그릴 시간을 주고 성공·실패 모두 잠금을 해제한다.
- 교재 선택 요청에 순번을 두어 이전 결과가 최신 선택을 덮지 못하게 한다. 목차 준비 중 다른 탭으로 갔다 돌아와도 결과를 보존하고, 실패 시 재시도·목록 복귀를 제공한다.

## 시안
총 30개. 기본형 01–05, 학원형 06–10, 개념형 11–15, 문제풀이형 16–20, 내신형 21–25, 모의고사형 26–30. 모두 컬러·Pretendard·A4 비율. 예시 문항만 사용한다. 1단/2단, 측면 필기, 개념 요약, 문제 박스, 여백, 제목과 번호 구조를 달리한다.

대화의 시안 선택기로 제시한다. 사용자가 번호 또는 이름으로 선택한 뒤에만 실제 인쇄 엔진에 이식하며, 그 단계에서 본문·정답/해설·표지·양면·QR·A4 쪽 높이를 검증한다. 이번 변경은 제품 인쇄 스타일·교재 높이표를 수정하지 않는다.

## 확인
단위 테스트: 중복 클릭, 오류 후 재시도, 권한 거절 시 오류 상태, 준비 중 탭 이동 후 결과 보존.
브라우저: 1440·820·390에서 실제 교재 목차와 쪽 범위 선택, 로딩·단일 채점 진입. 시안 30개 모두 794×1123 기준 크기 및 390px 가로 넘침 확인.
