# Solvi Symbols

Noto Sans CJK KR Regular의 U+2300–24FF, U+3200–32FF 중 원본에 있는 443개 기호만 남긴 WOFF2 파생본. 내부 글꼴 이름은 Solvi Symbols로 변경했다. 원문자·국어 지문 기호를 기기 시스템 글꼴에 의존하지 않고 출력한다.

원본: https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/Korean/NotoSansCJKkr-Regular.otf
라이선스: SIL Open Font License 1.1, SolviSymbols-OFL.txt 포함.
생성: fontTools subset, glyph 레이아웃 유지, name ID 1/2/3/4/6 변경. 원본 전체 글꼴은 저장소에 포함하지 않는다.
