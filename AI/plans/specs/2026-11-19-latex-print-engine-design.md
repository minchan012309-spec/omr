# 신규 자료의 브라우저 LaTeX 출력 설계

## 확정 요구

- 이미 만든 교재·학습지·모의고사는 HTML 출력과 기존 쪽수·QR을 유지한다. 날짜로 추측해 재분류하지 않는다.
- 새 교재는 기존 교재 디자인을 LaTeX로 옮기고, 새 학습지·모의고사는 첨부 XeLaTeX 양식으로 만든다. 생성자의 컴퓨터 자원을 사용하고 별도 조판 서버·유료 API를 추가하지 않는다.
- 학습지·모의고사의 기본 글꼴은 첨부 신명조·KoPubWorld Dotum Bold/Medium·HancomEQN을 그대로 사용한다. 원본이 지정한 STIX Two Math도 유지한다. 누락 시 대체하지 않는다.
- HWP 표지의 제목·과목명·필적확인 문구·기관명·유의사항을 수정할 수 있다. 학습지에서도 앞표지를 선택할 수 있다.
- 실제 쪽 나눔 결과에 QR 문항 목록과 표지 쪽 안내를 맞춘다. 구현 검증 후 PR을 올리고 병합하지 않는다.

## 접근 방식

처음 검토했던 별도 서버 방식은 사용자의 비용 제약으로 폐기했다. 수동 컴파일용 파일만 내려받는 방식도 기본 흐름으로 채택하지 않는다. 브라우저 Web Worker의 XeTeX·xdvipdfmx WebAssembly를 사용해 앱 안에서 PDF를 생성한다. GitHub Pages는 정적 파일을 제공하고 기존 Supabase는 QR 명세만 저장·조회한다.

## 호환성

출력 버전이 없는 자료는 항상 HTML이다. 새 생성과 명시적 복제에만 `printEngine: xelatex-v1`, `templateVersion: haewon-2026-v1`을 저장한다. 기존 자료의 이름·내용 편집은 엔진을 바꾸지 않는다. 새 교재는 원래 구성 ID에 고유 식별자를 더해 기존 구성을 덮어쓰지 않는다.

교재 PDF 명세는 정확한 교재/회차/간격과 출력 변형별로 보관한다. 채점 선택기에는 최종 PDF 쪽수를 사용한다. 같은 교재와 문항 묶음을 다시 출력하면 제출 잠금 키를 유지한다. 기존 HTML 높이표를 새 양식에 맞춰 재측정하지 않는다.

## 원본 양식

학습지·모의고사의 본문 템플릿은 첨부 6–10회 XeLaTeX preamble을 사용한다. 본문 신명조, 제목·문항 번호 KoPubWorld, 수식 HancomEQN/STIX 범위를 유지한다. 5지선다는 원본의 한 줄/3+2/세로 선지 매크로를 사용하고 다른 개수의 선지도 버리지 않는다. 보기·표·분수·MathML·그림·긴 지문을 변환한다. HTML 전체를 이미지로 찍어 PDF에 넣지 않는다.

HWP에서 용지 771.02×1116pt, 제목 Bold 25pt/장평 85%, 과목명 Bold 46pt, 본문 Medium 17pt를 확인했다. 종횡비를 유지해 A4에 맞춘 표지를 만들며 원본 예시 학교·기관·문구를 서비스의 사실로 복사하지 않는다. 본문은 원본의 상단12mm·하단16.5mm 여백과 첫 쪽195mm·후속235mm 단 높이를 사용한다. 실제 문항 높이를 측정해 짧은 문항의 칸은97.5/117.5mm를 유지하고, 긴 문항은 다음 단이나 이어지는 박스로 처리한다. QR은 본문 밖 하단에 배치한다.

## 실행과 저장

엔진·필요한 TeX 패키지는 정적 파일로 함께 제공한다. 외부 패키지 서버에 실행을 맡기지 않는다. 후속 사용자 지시에 따라 폰트 4개를 정적 사이트에 탑재하고 자동 로딩하며 원본 해시를 확인한다. 최초 등록 절차를 없앤다. 설정 변경은 자동 조판으로 반영하고 저장·인쇄할 때만 QR 명세를 확정한다.

문서 모델을 제한된 LaTeX로 변환하고 Worker에서 조판한다. 실제 shipout 로그의 쪽·문항·번호·구간을 수집한다. 표지·차례의 쪽 안내와 전체 쪽수가 안정될 때까지 최대 세 번 조판한다. 생성 취소·창 닫기·시간 초과는 해당 Worker를 종료한다. 실패하면 HTML로 전환하지 않는다.

Supabase에는 개인 정보 없는 불변 명세만 저장한다. PDF·폰트·학생 이름·문서 원문은 보내지 않는다. 테이블 전체 조회·수정·삭제 권한을 공개하지 않고 개별 식별자로 조회한다. 학습지 QR은 원래 학습지 번호로 연결해 제출·배정·잠금 흐름을 유지한다. 교재 QR은 최종 페이지 문항과 인쇄 번호로 채점하고 여러 쪽 선택·로그인 복귀를 지원한다.

## 검증 및 배포 경계

원본 PDF/TeX 7쪽 대조, 5개 과목의 실제 브라우저 PDF, 실제 문제은행 CSS 분수, 교재 생성·저장·채점 명세, 1440/820/390 출력 설정, 기존 HTML 회귀를 검증한다. 운영 반영 전 `supabase/sql_27_latex_manifests.sql` 적용이 필요하다. 이번 작업에서 운영 DB 변경·사이트 배포·PR 병합은 하지 않는다. 실제 Safari·휴대폰 기기 및 종이 인쇄는 별도 확인 범위다.

## 후속 양식 수정

원본의 12mm 상단 여백과 195/235mm 첫 쪽·후속 쪽 단 높이, 첫 쪽 회차/과목/쪽수와 후속 머리말을 사용한다. 해설도 2단이다. 지문 박스와 밑줄, 원문의 세로 선지 표시를 보존한다. 자동 선지는 실제 폰트 너비를 재어 5개 한 줄·3+2·세로 중 선택한다. 공통 지문 제목은 박스 밖에 놓고 같은 지문은 한 번 출력한다. 짧은 문항은 나누지 않고, 긴 문항도 첫 두 줄만 남기는 쪽 나눔은 금지한다.

## 2026-11-20 사용자 범위 교정

교재를 학습지·모의고사 양식과 공유하지 않는다. 기존 교재 디자인을 유지하면서 새 교재를 LaTeX로 옮기도록 사용자가 명시했다. 교재의 7개 표지·색상·로고·기존 글꼴·제본·목차·개념·문제·해설과 eBook 실시간 설정을 복구한다. 별도 `book-original-v1` 모델에서 기존 페이지의 위치와 본문 글꼴을 native XeTeX로 보존하고 비텍스트 장식/그림은 기존 자산으로 유지한다. 모의고사(`plan.kind==='m'`)는 첨부 시험지 양식을 사용한다.

학습지 생성 전 디자인 화면에도 실제 PDF를 자동으로 반영한다. 출력 창은 650ms 입력 대기 후 최신 설정만 반영한다. 원본 신명조·KoPubWorld·정확한 Pretendard 중 선택, 8~14pt, 유형명/문항코드 표시를 지원한다. 첫 두 줄만 남기는 지문/문항 조각은 다음 단으로 보낸다. 공통 지문 안내는 박스 밖, 지문은 한 번만 출력한다.
