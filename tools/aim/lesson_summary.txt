= TF–IDF=TF×{{N|DF}}
- TF: 해당 문서에서 센 횟수. DF: 등장한 문서 수. 로그형 IDF에서는 모든 문서에 등장하면 0

- 코사인은 영벡터, 자카드는 두 공집합에서 분모 0 처리 확인
- 감성 점수는 부정어의 적용 범위 확인 후 합산
