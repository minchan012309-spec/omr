# 역학과 에너지(ph) 문제 은행 — 생성기 작성 안내

한 유형(tag, 예: `ph019`)마다 **파이썬 함수 1개**를 만들어 문제를 자동으로 찍어 낸다. 목표는 유형당 **서로 다른 문항 90개**(최소 80개).
전체 113개 유형 ≈ 1만 문항이 되며, 학생이 학습지·교재·채점에 쓰는 데이터다. **정답이 틀리면 안 된다.**

## 파일
- `outline.py` — 단원·절·유형 표(읽기 전용). 각 유형의 `label`, `sec`(개념 절 번호), `desc`(출제 범위)가 적혀 있다.
- `phlib.py` — 도구 모음(읽기 전용). `mc()`, `bogi()`, `table()`, `FIG()`, `Fig`/`Plot`(SVG), `rad()`, `frac()` 등.
- `types_a1.py` — **기준 예시**. 문체·구조·그림을 이 파일처럼 쓴다(꼭 읽을 것).
- 내가 맡은 유형은 `types_XXX.py` 에 쓴다(담당 파일 이름은 지시문에 있음). 다른 파일은 고치지 않는다.

## 함수 규칙
```python
from phlib import *
@T('ph019')
def f(r, k):          # r = random.Random, k = 시도 번호. 반드시 r 로만 난수를 뽑는다(재현 가능).
    ...
    return mc(본문HTML, 정답문자열, [오답들…], steps=[풀이 줄…], core='핵심 개념', point='출제 포인트',
              lv='하|중|상', fam='a', r=r)          # 또는 bogi(...)
```
- `None` 을 돌려주면 그 시도는 버려진다(조건이 안 맞을 때 사용). `assert` 실패도 버려진다.
- 러너가 같은 본문+선택지는 자동으로 걸러 낸다. **90개가 모이려면 변수 조합이 충분히 많아야** 한다(숫자·상황·그림·묻는 대상을 바꾼다).
- `fam` 은 "문제 틀" 이름(a,b,c…)이다. **한 유형에 틀(구조)을 3가지 이상** 만든다(예: 계산형·그림형·<보기>형). 숫자만 바꾼 것은 같은 틀이다.
- `lv`: 하(공식 1번 대입·개념 1개), 중(2단계 또는 그림·표 해석), 상(3단계 이상·복합). 한 유형 안에서 **하 20~30%, 중 50~60%, 상 15~25%** 정도로 섞는다. 물리 과목이므로 상도 지나치게 어렵게 만들지 않는다(수능 3점 수준).
- `mc(..., sort='num')`(기본)은 선택지를 값 오름차순으로 놓는다(선택지가 숫자로 시작할 때). 문자·식·그림 설명이면 `sort='shuf'`.
- `bogi(intro, [(문장, 참거짓, 풀이문)×3], …)`: ㄱ·ㄴ·ㄷ 보기. 참이 **최소 1개**. 문장 은행(≥18개, 참·거짓 고르게)에서 3개를 뽑되 서로 모순되거나 같은 말인 조합은 피한다. 거짓 문장의 풀이문에는 **옳은 내용**을 적는다.
- 본문 HTML 은 `P('…')`(문단), `FIG(svg, '60%')`(그림), `table([...],[...])`, `BOGI`(bogi() 가 자동) 로 만든다. 아래첨자 `sub()`, 위첨자 `sup()`, 분수 `frac(a,b)`, 근호 `rad(a,b)`(=a√b), `num(x)`(숫자 다듬기), `U(x,'N')`.
- 풀이 `steps` 는 **실제 숫자를 넣은** 풀이 과정(2~5줄). 마지막 줄에 답이 나오게. `core`(핵심 개념 한 문장), `point`(출제 포인트 한 문장)는 꼭 쓴다.
- 오답 선택지는 **학생이 실제로 하는 실수**(부호·단위·공식 혼동·절반/2배·제곱 빠뜨림)에서 만든다. 정답과 값이 겹치지 않게(중복은 자동 제거되지만 5개가 모자라면 그 시도가 버려진다).

## 물리 약속
- 중력 가속도 g = 10 m/s², 공기 저항·마찰은 말이 없으면 무시. 소리 속력 340 m/s(문제에 따라 다른 값을 주어도 됨). π는 계산이 필요하면 문제에서 "π=3" 으로 준다.
- sin30°=1/2, cos30°=√3/2, sin37°=0.6, cos37°=0.8, sin45°=√2/2, sin53°=0.8, cos53°=0.6, sin60°=√3/2.
- 답이 **정수·간단한 소수(소수 둘째 자리까지)·간단한 근호**가 되게 값을 고른다. 숫자 선택은 `r.choice` 로 "깨끗한 값" 목록에서 뽑는 게 안전하다.
- 단위는 SI(m, kg, s, N, J, W, Pa, K, Hz). 이상 기체 문제에서 1기압=1.0×10⁵ Pa 로 주고 단위 변환(L→m³)은 문제에서 명시.
- 한국 내신·수능 문체: "~인 것은?", "(단, ~는 무시한다.)", "이에 대한 설명으로 옳은 것만을 <보기>에서 있는 대로 고른 것은?". 그림이 있으면 "그림은 …를 나타낸 것이다."
- **교재·기출 문제를 베끼지 않는다.** 일반적인 개념·공식·전형적 상황만 쓰고 문장·수치·그림은 새로 만든다.

## 그림(SVG)
- `Fig(w,h)`/`Plot(w,h,xmax,ymax,…)` 로 그린다(`phlib.py` 참고). 크기 ≤ 340×230. 글자 크기 ≥ 11.5. 축에는 물리량과 단위, 눈금 값을 쓴다.
- 그림 속 값이 문제 풀이에 필요한 모든 정보를 담아야 한다(그림과 본문의 숫자가 어긋나면 안 된다). 라벨이 겹치지 않게 확인한다.
- 같은 그림 함수를 여러 유형에서 쓰고 싶으면 **자기 파일 안에** 만든다(다른 담당자 파일에서 import 하지 않는다).

## 실행·검사 (반드시)
```
cd /home/user/omr
python3 tools/ph/build.py --tags ph019,ph020 --n 90 --out /tmp/ph_<이름>      # 생성+자동검사(출력 폴더를 반드시 /tmp 로!)
node tools/ph/view.js /tmp/ph_<이름>/ph019.json 0 6 /tmp/ph019.png 1           # 앱 렌더러로 그림 확인(그림 파일을 Read 로 열어 본다)
```
- `ph/` 폴더에는 쓰지 않는다(다른 담당자와 충돌). 앱 서버(8765)는 이미 켜져 있다. 꺼져 있으면 `cd /home/user/omr && (nohup python3 -m http.server 8765 &)`.
- build 출력의 `N/90` 에서 N 이 80 미만이면 변수 조합을 늘린다. `{'중복':…}` 가 크면 조합이 부족하다는 뜻.
- **정답 검증**: 생성기 안에서 정답을 두 가지 방법으로 계산해 `assert` 로 맞춰 보거나, 별도 스크립트로 표본 20개 이상을 손으로 검산한다. 선택지가 정답과 우연히 같은 값이 되는 경우를 막는다.
- `view.js` 로 유형마다 **그림 있는 문항·<보기> 문항을 포함해 6~12개**를 눈으로 확인한다(선택지·표·그림이 문제에 맞는지, 풀이가 숫자와 맞는지).
